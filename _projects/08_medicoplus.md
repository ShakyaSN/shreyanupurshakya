## Overview

**MedicoPlus** is a wellness-centre appointment platform designed to support interactions between customers and wellness-service providers through a structured digital experience.

The project explored how a service-based business workflow could be translated into a user-facing software application.

Developed as an academic software project at **Jain University**.

## Problem

Appointment-based services require coordination between customers, available services, and scheduling workflows.

The project focused on translating these real-world interactions into a structured application experience that could make appointment-related activities easier to manage.

## Product Approach

We approached the application by identifying the major user and business workflows that the system needed to support.

The project involved:

- Translating the service concept into application requirements
- Identifying core user workflows
- Defining and organizing application functionality
- Connecting user-facing interactions with underlying system behavior
- Developing the application iteratively
- Testing functionality across workflows

## User Experience

A key consideration was keeping the application centered on the customer's journey through the service.

Rather than treating individual screens as independent features, the project considered how users would move through the application and interact with appointment-related functionality.

This required thinking about:

- Information users need before taking an action
- Logical sequencing of interactions
- Consistency across application workflows
- How application behavior maps to the underlying service process

## Development

The platform was implemented as an end-to-end software application, connecting the user-facing experience with the application's underlying logic and data.

Development involved translating requirements into working functionality and validating the application through iterative implementation and testing.

## Product Takeaways

MedicoPlus provided early experience thinking about software from both the **user and business-process perspectives**.

The project reinforced the importance of:

- Understanding the workflow behind a product before designing features
- Translating real-world processes into clear software requirements
- Designing around complete user journeys
- Connecting technical implementation with user-facing functionality
- Iterating on features through implementation and testing

The project helped build a foundation for my later work across **software engineering, requirements analysis, and product development**.
