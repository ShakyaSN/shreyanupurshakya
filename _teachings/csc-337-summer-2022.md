## Course Overview

CSC 337 introduces students to the techniques and technologies used to develop dynamic websites and full-stack web applications.

### Topics

- HTML and CSS
- CSS layout
- JavaScript
- DOM
- Event-driven programming
- HTML forms and form validation
- Regular expressions (REGEX)
- PHP
- Server-side processing with PHP
- AJAX and JSON
- MVC
- Relational databases
- SQL
- PHP Data Objects (PDO)
- Higher-order functions
- Database design and joins
- Cookies and sessions
- Web security vulnerabilities
