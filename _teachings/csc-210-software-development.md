## Course Overview

CSC 210 introduces students to the development of large-scale software and the tools and practices required to move beyond writing small programs.

Topics include:

- modularization and program decomposition
- object-oriented programming in Java
- design patterns
- documentation
- unit testing and debugging
- source code control
- build systems
- data structures and their implementations
- performance considerations

The course emphasizes decomposing larger software problems into manageable components, testing and debugging individual components, and integrating them into complete working systems. :contentReference[oaicite:0]{index=0}

## Learning Objectives

Students developed experience with:

- decomposing software specifications into smaller problems
- developing multi-class Java applications
- inheritance and hierarchical data structures
- unit testing and debugging
- selecting appropriate data structures
- comparing implementation efficiency
- evaluating software decomposition, clarity, performance, and style

These objectives are documented in the course syllabus. :contentReference[oaicite:2]{index=2}
